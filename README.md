## Publish on GitHub Pages
1. Open your `USERNAME.github.io` repository.
2. Upload all files and the `images` folder.
3. Commit changes.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch → main → / (root)**.
6. Save.

The content is based primarily on the NIT Jalandhar/IRINS academic profile. Verify publication details and update them whenever the institutional record changes.
